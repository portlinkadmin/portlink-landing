# PortLink Landing Page

Public marketing landing page for [PortLink](https://portlink.app) — operational coordination infrastructure for the cruise industry.

## Structure

```
index.html          Main landing page
assets/             Images and logos
css/                Stylesheets (tokens, DS styles, fonts)
js/                 nav.js (mobile nav + theme toggle)
```

## Deploy

Deployed via Netlify. Push to `main` → auto-deploys.

## Design System

Styles are sourced from `portlinkadmin/portlinkapp` (design system v3).
When updating tokens or DS styles, copy from `design-system-v3/` into `css/` here.
